# Chi C◆ Logo

The canonical Chi mark is a simple **C◆** construction:

- a solid square rotated 45° to form the diamond background;
- the selected `Geekomet Demo` C typography centered on top;
- a fixed 100 × 100 viewBox and consistent proportions.

## Variants

- `chi-mark-wb.svg`: black diamond with white C, suitable for dark surfaces.
- `chi-mark-bw.svg`: white diamond with black C, suitable for light surfaces.

These SVGs preserve the compact vector construction used by the existing Chi NAV `wb.svg` asset. The original NAV asset defines the 100 × 100 mark, a 70 × 70 rotated square, and the centered C typography. Product repositories should use these canonical assets rather than redrawing the mark.

## Color variants

Do not create separate logo geometry for each website. When a branded-color mark is needed, recolor the existing shapes while preserving the geometry and contrast requirements.
