# Chi Brand

Shared visual identity for the Chi web ecosystem.

## Sites

- `chi.qzz.io` · Main Chi site · `#356AE6`
- `nav.chi.qzz.io` · Tools / navigation · `#1687E8`
- `merch.chi.qzz.io` · Collection database · `#0FA3A3`

## Core mark

The ecosystem shares the **C◆** logo: the selected C typography with a solid square rotated 45° behind it. Geometry and proportions stay consistent across sites.

## Repository role

This repository is the source of truth for shared brand assets, palette, and usage guidance. Individual product repositories own their UI implementation and product-specific design systems.

See [`BRAND.md`](./BRAND.md) for the current brand guidelines and [`colors/tokens.css`](./colors/tokens.css) for the initial semantic color tokens.
